# Проверка индикатора MultiFunction Shield HW-262 V0.0.5 (Arduino UNO R3)

Отдельное приложение для проверки драйвера
[`MFShieldDisplay`](../../../../lib/MFShieldDisplay/src/mfshield_display.hpp)
на 4-разрядном семисегментном индикаторе шилда (2 x 74HC595).

## Подключение

Шилд устанавливается на Arduino UNO R3. Дополнительных проводов не нужно.

| Сигнал 74HC595 | Пин UNO |
|----------------|---------|
| LATCH (STCP)   | D4      |
| CLOCK (SHCP)   | D7      |
| DATA (DS)      | D8      |

Кнопки шилда: S1 = A1, S2 = A2, S3 = A3 (нажатие - LOW).
Светодиоды D1-D4: D13-D10 (активны при LOW), зуммер: D3.

## Сборка и прошивка

Из каталога этого примера:

```console
pio run -e uno
pio run -e uno -t upload
pio device monitor -b 115200
```

## Что показывает приложение

Фазы повторяются по кругу:

1. `8888` - проверка всех сегментов (1 с).
2. Каждый поддерживаемый символ (`0-9`, `A`, `C`, `E`, `F`, `H`, `L`, `P`,
   `U`, `-`, `_`) во всех четырёх знакоместах (0.6 с на символ).
3. `1.2.3.4` - все четыре десятичные точки (1.5 с).
4. Строки `0123`, `4567`, `89AC`, `EFHL`, `PU-.` (0.8 с на строку).
5. Ступени яркости `3 -> 2 -> 1 -> 0`, затем возврат к фазе 1.

В последовательный порт на 115200 выводится текущая фаза/символ и действия
кнопок.

## Кнопки

| Кнопка | Действие |
|--------|----------|
| S1 (A1) | Полярность: `Classic` <-> `InvertedClone` |
| S2 (A2) | Порядок знакомест: прямой <-> зеркальный |
| S3 (A3) | Яркость 0..3 вручную |

## Если индикатор работает неправильно

- **Символы "мусорные", горят не те сегменты или индикатор тёмный** -
  нажмите S1: у части клонов шилда инвертированы и сегменты, и выбор
  разряда (`Wiring::InvertedClone`).
- **Строка выводится справа налево** - нажмите S2
  (`setReverseDigits(true)`).
- **Индикатор вообще не светится** - проверьте, что шилд плотно надет на
  UNO, и что в прошивке выбрана плата `uno` (16 МГц). Также убедитесь, что
  не используются пины D4, D7, D8 для других целей.
- **Один разряд заметно ярче/тусклее** - уменьшите яркость кнопкой S3 или
  проверьте, не блокируется ли `loop()` длительными операциями: `refresh()`
  должен вызываться часто.

## Использование драйвера в своём проекте

```cpp
#include <mfshield_display.hpp>

MFShieldDisplay display;  // LATCH=D4, CLOCK=D7, DATA=D8

void setup() {
    display.begin();
    display.setBrightness(3);
    display.print("12.34");
}

void loop() {
    display.refresh();  // динамическая индикация, без таймеров
}
```

Для нестандартной ревизии шилда пины задаются конструктором:
`MFShieldDisplay(latch, clock, data)`.
