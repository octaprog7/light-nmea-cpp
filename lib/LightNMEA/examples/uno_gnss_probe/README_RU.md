# uno_gnss_probe - диагностика обмена с GNSS

Проверочная прошивка для Arduino UNO R3: показывает, что модуль не только
передаёт NMEA, но и **принимает команды** (чтение конфигурации по UBX).
Фикс для проверки не нужен - модуль отвечает и без него.

## Подключение

| Провод модуля | Назначение | Пин UNO |
|---------------|------------|---------|
| синий | TX (выход NMEA) | `D5` (SoftwareSerial RX) |
| зелёный | RX (вход) | `D6` (SoftwareSerial TX) |
| красный | VCC | `5V` |
| чёрный | GND | `GND` |

`D0`/`D1` и разъём APC220 шилда не использовать - это аппаратный UART,
он нужен USB-загрузчику.

## Что выводит

- `NMEA: <строка>` - все строки от модуля (GGA, GLL, GSV, RMC, ...).
  Без фикса координаты пустые, но строки идут и спутники видны в GSV.
- `UBX: cls=.. id=.. len=..` - заголовок любого UBX-ответа.
- `MON-VER sw=... hw=...` - версия прошивки и железа модуля.
- `CFG-PRT baud=... inMask=... outMask=...` - текущая скорость порта
  и разрешённые протоколы (вход/выход).
- `--> UBX-... poll` - запрос, отправленный модулю.

Каждые 3 секунды по очереди отправляются запросы `UBX-MON-VER` и
`UBX-CFG-PRT` (пустой payload, только опрос).

## Буфер приёма

Штатный буфер SoftwareSerial - 64 байта (`_SS_MAX_RX_BUFF`), но ответ
`UBX-MON-VER` занимает 160 байт payload (168 с заголовком и CRC). Пока
прошивка печатает NMEA в USB, 64 байта переполняются и ответ теряется.
Поэтому в `platformio.ini` буфер увеличен:

```
-D_SS_MAX_RX_BUFF=256
```

Это +192 байта RAM: прошивка занимает 1241 из 2048 байт (60.6%).
На самой UNO для основного приложения это не требуется - там NMEA-строки
короткие, а буфер строки `BUFFER_SIZE = 128` в `src/main.cpp`.

## Сборка и прошивка

```console
cd lib/LightNMEA/examples/uno_gnss_probe
pio run -e uno -t upload --upload-port /dev/ttyUSB0
pio device monitor -b 115200
```

## Как читать результат

- Идут `NMEA:` строки - приём работает, скорость и провод TX верные.
- Пришёл `MON-VER sw=...` - модуль принимает команды, провод RX (зелёный)
  подключён правильно.
- `CFG-PRT baud=38400` - заводская скорость подтверждена.
- `inMask`/`outMask` содержат бит `0x01` (UBX) и `0x02` (NMEA) - какие
  протоколы разрешены на порту.
- Нет ответов на опрос, но NMEA идёт - проверьте зелёный провод (`D6`).
- Нет вообще ничего - проверьте питание, общий GND и скорость 38400.
